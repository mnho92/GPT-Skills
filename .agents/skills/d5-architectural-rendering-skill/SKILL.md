# D5 건축 외관 렌더링

한국어로 간결하게 소통한다. 이 파일만으로 작업한다. 다른 Skill이나 Arch Studio에 의존하지 않는다.

## 핵심 원칙

1. 건축 형상과 카메라는 기본적으로 고정한다.
2. 렌더 요청을 모델 재설계 요청으로 해석하지 않는다.
3. D5 Lite CLI/에이전트 연결에서 실제로 검증된 기능만 자동 실행한다.
4. 확인되지 않은 CLI 명령이나 파라미터를 추측하지 않는다.
5. CLI에서 지원되지 않는 단계만 UI 작업으로 전환한다.
6. 테스트 렌더 → QA → 수정 → 최종 렌더 순서를 지킨다.

## 사용자 입력 형식

사용자 요청은 아래 3개 항목을 우선 해석한다.

### 1. 렌더 환경
- 시간대
- 날씨/광원
- 분위기
- 필요 시 HDRI 또는 Geo Sky 조건

### 2. 건축물 특징
- 외장재
- 유리
- 석재/목재/금속 등 주요 마감
- 반드시 유지할 형상·창호·카메라 조건

### 3. 출력 결과물
- 준공사진형 / 미팅용 / 재료 비교용 등 목표
- 해상도와 화면비
- Main Render
- 필요 시 MaterialID / SkyMask / Reflection / Transparent

정보가 일부 없어도 작업을 시작할 수 있으면 먼저 합리적인 기본값을 적용하고, 실제 실행을 막는 누락만 확인한다.

## 실행 모드 판단

작업 시작 시 다음 중 하나로 분류한다.

- **실행 모드**: 현재 컴퓨터의 D5 Lite CLI 또는 공식 에이전트 연결에 접근 가능.
- **수동 지원 모드**: D5 Lite는 있으나 CLI/에이전트 실행 접근이 없음.
- **이미지 검토 모드**: 렌더 이미지나 캡처만 제공됨.

실행 모드가 아닌데 렌더를 직접 완료했다고 표현하지 않는다.

## D5 Lite 연결

공식적으로 지원되는 현재 설치본과 호스트를 확인한다.

- Windows에서는 현재 SketchUp용 Lite 설치본의 공식 연결 도구를 우선한다.
- 설치본 버전, SketchUp 호스트, 현재 프로젝트가 맞는지 읽기 전용으로 먼저 점검한다.
- 환경·조명·재질·카메라·후처리·이미지 렌더 등은 CLI 기능군이 공개되어 있어도 각 세부 값이 실제로 노출되는지 설치본에서 확인한다.
- Scene 전환, 채널 선택, 저장 위치, 배치 렌더 등은 실제 지원 여부를 확인한 후 사용한다.
- Mac에서는 Windows 실행 절차를 그대로 가정하지 않는다.

## Geometry Lock

사용자가 명시적으로 허용하지 않으면 다음을 변경하지 않는다.

- 매스, 층수, 층고
- 지붕선과 실루엣
- 창호 위치, 크기, 개수, 분할
- 슬래브, 난간, 처마
- 입면 모듈
- 대지, 도로, 인접 건물

형상 결함을 발견하면 렌더 단계에서 임의로 고치지 말고 별도 수정사항으로 보고한다.

## Camera Lock

기준 Scene이 있으면 그대로 사용한다.

유지 대상:
- 카메라 위치
- 타깃
- FOV/초점거리
- 투영 방식
- 화면비
- 크롭
- 수직선 및 소실점 관계

더 좋아 보인다는 이유로 재구도하거나 2점투시를 임의 적용하지 않는다.

## 재료

레퍼런스 이미지는 색조·거칠기·반사·투명감·빛 분위기 참고용으로만 사용한다.

- 사진만으로 정확한 제품명·색번호·물성값을 확정하지 않는다.
- 금속, 석재, 도장, 목재, 유리의 물성을 서로 혼동하지 않는다.
- 유리는 지나치게 투명하거나 검은 거울처럼 보이지 않도록 반사·거칠기·실내 가시성을 함께 본다.
- 텍스처 반복, 줄눈, 패널 크기, UV 방향을 실제 스케일에 맞춘다.
- 실루엣을 바꾸는 과도한 displacement는 사용하지 않는다.
- 공유 재료가 다른 면에도 적용되는지 확인한다.

## 환경과 조명

작업 순서:

1. 환경 기준 확정
2. 재료
3. 조명
4. 후처리
5. 테스트 렌더

- 실제 특정 시각을 재현할 때는 SketchUp의 위치·북향·날짜·시간 정보를 우선한다.
- "오후 4시 느낌"과 실제 특정 날짜 오후 4시 일조를 구분한다.
- 재료 옵션 비교에서는 환경·조명·노출을 동일하게 유지한다.
- 요청받지 않은 연출 조명을 임의로 추가하지 않는다.
- 노출은 후처리로 과도하게 보상하지 않는다.

## 옵션 비교

재료 비교 시 변경 축은 하나씩 유지한다.

예:
- BASE: 현재안
- ALT-A: 샴페인 알루미늄
- ALT-B: 브론즈 알루미늄

카메라·환경·조명·노출·화면비는 동일하게 유지한다.

각 옵션은:
BASE 복원 → Scene 선택 → 재료 적용 → 잠금조건 확인 → 테스트 렌더 → QA → 최종 렌더 순서로 처리한다.

Scene만 복제하면 재료 상태가 완전히 격리된다고 가정하지 않는다. 필요하면 모델 사본 또는 검증된 복원 절차를 사용한다.

## 출력

기본 권장:
- 검토본: Standard
- 최종본: High PNG
- 사용자 요청이 있으면 4K 수준 출력 가능 여부를 설치본에서 확인
- 필요 시 MaterialID / SkyMask / Reflection / Transparent

채널 선택을 CLI에서 확인할 수 없으면 UI로 설정한다.

파일명 권장:
`프로젝트_뷰_옵션_주야_YYYYMMDD_vNN_BEAUTY.png`

## QA

최종 출력 전 아래를 확인한다.

1. 기준 이미지와 비교해 지붕선, 코너, 층선, 창호, 난간, 대지 경계가 바뀌지 않았는지 확인.
2. 카메라 수치를 읽을 수 있으면 전후 비교.
3. 재료 누락, UV 왜곡, 과도한 반사·투명도, 하이라이트 클리핑, 과포화를 확인.
4. 출력 파일이 실제로 열리는지 확인.
5. 채널은 원본과 같은 구도·해상도인지 확인.
6. 기준 위반 출력은 FINAL로 분류하지 않는다.

## 실패 시

- CLI 연결 실패: 설치본·사용자·SketchUp 호스트·Lite 로딩 상태를 확인.
- 특정 기능 미지원: 해당 단계만 UI로 전환.
- 실행 도구 없음: 설정표와 UI 작업 순서까지만 제공.
- 이미지밖에 없음: 렌더 품질 검토와 수정 지침 제공.
- 생성형 실사화가 필요하면 원본 모델 렌더와 구분해 AI-CONCEPT으로 관리.

## 기본 호출 예시

현재 열려 있는 SketchUp + D5 Lite 프로젝트에 이 Skill을 적용해줘.

### 렌더 환경
- 오후 4시
- 부드러운 자연광
- 차분하고 자연스러운 건축사진 분위기

### 건축물 특징
- 외장: 샴페인 알루미늄
- 유리: 반사 중간, 투명도 낮게
- 현재 건물 형상과 카메라 유지

### 출력 결과물
- 실제 준공사진처럼 자연스럽게
- 재료 질감과 유리 반사를 과장하지 않기
- High/4K 수준 최종 렌더
- MaterialID / SkyMask 필요 시 함께 출력
