# Building Replacement Skill

현장사진·거리뷰에서 기존 건축물만 새 설계안으로 교체하는 건축 시각화 Skill입니다.

## 목적

- 리모델링/신축 Before & After
- 설계안 현장 합성
- 건축주 미팅용 외관 비교
- 같은 배경에서 ALT 비교

## 설치 경로

`.agents/skills/building-replacement/`

## 호출

`$building-replacement`

예:

1번 이미지는 현장사진, 2번 이미지는 신축 설계안이야.
1번의 주변 건물, 도로, 사람, 차량, 날씨, 카메라는 그대로 두고
가운데 대상 건물만 2번 건물로 교체해줘.
2번 건물의 4층 규모와 밝은 회색 마감은 유지해줘.

## 기본 규칙

주변 환경은 고정하고 대상 건축물만 교체합니다. 후속 수정에서는 이전에 승인된 요소를 유지하면서 요청된 부분만 변경합니다.
