# 건축물 교체 합성

기존 현장사진 또는 거리뷰 안에서 **대상 건축물만 교체**한다. 주변 환경을 새로 생성하는 작업이 아니다.

## 핵심 원칙

1. TARGET BUILDING만 변경한다.
2. 카메라, 원근, 화면비, 크롭을 유지한다.
3. 주변 건물·도로·차량·사람·가로수·전봇대·표지판·날씨·하늘·빛 방향은 유지한다.
4. 사용자가 요청하지 않은 요소를 정리하거나 미화하지 않는다.
5. 새 건축물은 실제 대지에 존재하는 것처럼 자연스럽게 합성한다.
6. 설계안의 매스와 입면 특징을 임의로 재해석하지 않는다.

## 입력 이미지 역할

가능하면 이미지를 아래처럼 구분한다.

- **BASE IMAGE**: 교체 전 현장사진/거리뷰. 카메라와 주변 환경의 기준.
- **REPLACEMENT REFERENCE**: 교체할 설계안, 렌더, 모델 캡처 또는 다른 건축물 이미지.
- **DETAIL REFERENCE**: 재료, 창호, 루버, 유리, 색상 등 세부 참고.

사용자가 이미지 번호를 지정하면 그 번호를 그대로 따른다.

## Scene Lock

BASE IMAGE에서 다음은 잠금 상태다.

- 카메라 위치와 높이
- 렌즈 느낌과 원근
- 소실점
- 화면비와 크롭
- 좌우 인접 건물
- 도로와 보도
- 차량
- 사람
- 식재
- 가로시설물
- 하늘과 날씨
- 그림자 방향
- 전체 노출과 시간대

교체 대상 건물을 제외한 영역은 가능한 한 픽셀 단위로 보존하는 것을 목표로 한다.

## Target Building Lock

먼저 기존 대상 건물의 실제 범위를 특정한다.

- 대지 폭
- 도로 접면
- 좌우 경계
- 건물 높이
- 층수
- 전면/측면 노출 범위
- 지면 접점

교체 후 건축물은 BASE IMAGE의 대지와 원근에 맞춰야 한다.

사용자가 "규모는 2번 이미지의 건물로 축소"처럼 지시하면 대상 참조의 규모와 층수를 우선한다.

## 형태 보존

교체 대상 설계안에서 사용자가 지정한 형상은 유지한다.

예:
- 4층/6층 규모
- 코너 창
- 수직 루버
- 층간 수평 프레임
- 옥탑 유무
- 1층 슬라브 라인
- 우측면 창
- 출입구 위치

명시되지 않은 부분을 임의로 추가하지 않는다.

## 재료와 디테일

사용자의 수정 지시는 누적해서 유지한다.

예:
- 브론즈/샴페인 금속
- 트래버틴
- 짙은 회색 파벽돌
- 흰색 알루미늄 시트
- 검정 석재
- 유리 투명도 30% 낮추기
- 금속 루버 두께 1/2
- 수직 루버 제거
- 층간 금속을 커튼월 유리로 변경

재료 변경 시 건물 형상, 카메라, 주변 환경까지 같이 바꾸지 않는다.

## 합성 순서

1. BASE IMAGE에서 대상 건물 범위를 식별.
2. 주변 환경과 카메라를 Lock.
3. REPLACEMENT REFERENCE의 매스·층수·주요 입면 요소 분석.
4. 새 건물을 BASE IMAGE 대지와 원근에 맞춰 배치.
5. 기존 대상 건물 영역만 교체.
6. 하늘·빛·그림자·노출을 주변과 맞춤.
7. 재료와 창호 디테일 조정.
8. 경계, 접지, 그림자, 반사 확인.
9. 최종 QA.
10. 필요 시 Before / After 세트 출력.

## Iteration 규칙

사용자가 후속 수정 요청을 하면 이전에 확정한 조건을 유지한다.

예:
- "우측면 창은 다시 살려줘."
- "좌측 유리건물은 삭제해줘."
- "옥탑 돌출은 없애줘."
- "유리 투명도를 30% 낮춰줘."
- "금속루버 두께를 절반으로 줄여줘."

수정 요청 하나 때문에 이미 승인된 다른 요소를 되돌리지 않는다.

## QA

최종 이미지 전 확인:

1. 주변 건물 위치와 형태가 바뀌지 않았는가?
2. 도로·보도·차량·사람·식재가 유지됐는가?
3. 카메라와 원근이 BASE와 같은가?
4. 대상 건물의 대지 폭과 지면 접점이 자연스러운가?
5. 새 건물 층수와 높이가 요청과 맞는가?
6. 창호·루버·재료가 요청과 맞는가?
7. 그림자 방향과 밝기가 주변과 일치하는가?
8. 건물 외 영역에 생성형 왜곡이 생기지 않았는가?
9. 간판·전선·가로시설물 등 기존 요소가 불필요하게 사라지지 않았는가?
10. Before/After 비교가 가능한가?

## 기본 출력

- Replacement Final
- 요청 시 Before / After
- 요청 시 배경 제거 건물 PNG
- 요청 시 고해상도 업스케일본

## 기본 호출 예시

1번 이미지를 BASE IMAGE로 사용하고 2번 이미지의 건축물로 교체해줘.

- 주변 환경, 도로, 차량, 사람, 인접 건물, 날씨, 카메라와 원근은 전부 유지.
- 대상 건물만 교체.
- 2번 건물의 층수와 규모를 유지.
- 외장재와 창호 디테일도 최대한 보존.
- 실제 그 대지에 신축된 준공사진처럼 자연스럽게 합성.
